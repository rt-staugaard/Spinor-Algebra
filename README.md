This project is an attempt at building an algebra system for spinor-helicity objects. It includes a library with functions to add, subtract, divide and multiple expressions among other things. I have also made a module to test various cases to make sure my implementation works. Currently, it clears all the tests I have assigned.

This project is currently undergoing an update. I used to do things quite differently, having a different struct for each type of expression, but now I have moved over to general tree-based nested expressions.

I have a bunch of features I want to add to this project, including actually being able to evaluate expressions numerically.
